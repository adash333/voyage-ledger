大航海商人アカデミー（Voyage Ledger／https://v.5micro.net/）

はじめに

大航海商人アカデミー（以下「当サイト」）は、小学生を含む多くの方に安心して使っていただけるよう、利用者の情報の扱いを次のとおり定めます。

当サイトはアカウント登録がなく、名前・メールアドレス・住所などの個人情報を入力していただく場面はありません。

1. セーブデータ（ブラウザ内の保存）

ゲームの進み具合は、お使いのブラウザの保存領域（localStorage）にだけ保存します。このデータが当サイトの運営者や外部に送られることはありません。ブラウザの設定から削除でき、各ゲームの「最初から遊ぶ」でも消去できます。

「ファイルに保存」で書き出したセーブファイルは、利用者の端末に保存されるだけで、当サイトには送信されません。

2. 広告の配信について

当サイトでは、第三者配信の広告サービス「Google アドセンス」を利用することがあります。

  • Google などの第三者配信事業者は、Cookie を使用して、利用者が当サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信することがあります。
  • Google が広告 Cookie を使用することにより、Google やそのパートナーは、当サイトや他のサイトへのアクセス情報に基づいて利用者に広告を配信できます。
  • 利用者は、Google の広告設定でパーソナライズ広告を無効にできます。また、www.aboutads.info にアクセスすると、第三者配信事業者の Cookie を無効にできます。
  • Google による情報の扱いについては、Google のポリシーと規約（パートナーのサイトやアプリでのデータ使用）をご覧ください。
  • 小学生向けのページでは、利用者の興味・関心にもとづくパーソナライズ広告を配信しない設定で運用します。

3. アフィリエイトについて

当サイトは、Amazon.co.jp を宣伝しリンクすることによってサイトが紹介料を獲得できる手段を提供することを目的に設定されたアフィリエイトプログラムである、Amazon アソシエイト・プログラムの参加者です。

Amazon のアソシエイトとして、当サイトは適格販売により収入を得ています。商品リンクから購入された場合、運営者が紹介料を受け取ることがありますが、利用者の購入価格は変わりません。

4. アクセス解析について

当サイトでは、サイトの改善のために Google アナリティクスなどのアクセス解析ツールを利用することがあります。これらのツールは Cookie を使ってトラフィックデータを収集しますが、個人を特定する情報は含みません。Cookie はブラウザの設定で無効にできます。Google アナリティクスの詳細は Google アナリティクス利用規約をご覧ください。

また、当サイトは GitHub Pages で配信しており、配信の過程でアクセス元の IP アドレスなどが GitHub によって記録されることがあります（GitHub のプライバシーステートメント）。

5. お子さまの利用について

当サイトはお子さまに使っていただくことを想定しています。外部サイト（広告や商品リンクを含む）へ移動する前や、お問い合わせをする際は、おうちの方と一緒にご確認ください。

6. お問い合わせ・改定

このポリシーについてのお問い合わせは、運営者情報に記載の方法でお寄せください。

本ポリシーの内容は、法令の変更や当サイトの運営方針により、予告なく改定することがあります。改定後の内容はこのページに掲載した時点から有効となります。
