# SPEC-QUIZ-EN-001 英語版「大航海時代の商人チャレンジ！」

- URL: `/quiz/en/`。タイトルは “Age of Discovery Merchant Challenge!”、HTML の言語は `en`。
- 日本語版 `/quiz/`（SPEC-QUIZ-002）と同じ取引・設問順・正答の10問。各問三択、10点、満点100点。
- 元手100、仕入60、売上90、売上原価60、最終現金130、利益30、仕訳合計310を使用する。
- 借方（Debit / left）・貸方（Credit / right）の2列を表示。勘定科目または金額の `(?)` を埋め、仕訳・資本金と利益・貸借一致を理解する。
- 全設問、勘定科目、選択肢、進捗、ボタン、正誤、解説、結果、再挑戦をやさしい英語で表示する。日本語版への言語切替リンクのみ日本語を含めてよい。
- 未選択では進めない。選択は答え合わせ前なら変更でき、確定後は変更できない。正誤を文字で伝え、正解と理由を表示してから次へ進む。
- 全10問の確定後に0〜100点の合計・正解数・得点に応じた励ましを表示する。
- “Try again” は問題番号・回答・得点・選択・解説をすべて初期化し、1問目に戻す。再挑戦に前回の回答を持ち越さない。
- アカウント・外部API不要。クイズは回答の保存や個人データ収集を行わず、既存ゲームのセーブに触れない。

## SPEC-QUIZ-EN-002 英語の導線

- `/history/en/` の “Merchant Challenge (Japanese)” を “Merchant Challenge” に変更し、`../../quiz/en/` にリンクする。
- `/en/` の学習後のページ下部に “Try the Merchant Challenge” → `../quiz/en/` を設置する。
- クイズから英語トップ・英語歴史ページ・日本語クイズに戻れる。
- GitHub Pages の `/voyage-ledger/` 配下でも成立する相対パスを使う。
- 日本語版の設問・動作を維持し、最新mainの先行変更を保持する。

## SPEC-QUIZ-EN-003 スマートフォンとアクセシビリティ

- 幅320px・360px・390pxで全問題と結果に横スクロールがなく、借方・貸方を2列で読める。
- 回答ボタンは高さ48px以上。長い勘定科目は折り返す。
- キーボードでも選択・確定・次問・再挑戦ができる。選択状態は `aria-pressed`、進捗・解説はライブ領域で伝える。
- 次問・結果・再挑戦の移動時は見出しへフォーカスを移す。

## 検証
