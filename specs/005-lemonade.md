# SPEC-LEMON-001 レモネード屋さんの複式簿記
対象：小学生。独立した `/lemonade/` ページで5ステップを閲覧する。単位は円。

1. 自己資金500円：借方 現金500 / 貸方 元手500
2. 500円を借りる：借方 現金500 / 貸方 借入金500
3. 材料600円を現金購入：借方 材料600 / 貸方 現金600
4. 全材料を使いレモネードを1200円で現金販売：借方 現金1200 / 貸方 売上1200、借方 売上原価600 / 貸方 材料600
5. 借入金500円を返済：借方 借入金500 / 貸方 現金500

全ステップで 資産（現金＋材料）＝負債（借入金）＋元手＋累積利益。
終了時：現金1100円、材料0円、借入金0円、元手500円、利益600円。
注意：借方は常に「増加」ではなく、貸方は常に「原因」ではない。借入金返済時には借方で負債を減らす。
参考画像は表現・画面設計の参照であり、会計計算は独立して定義する。
