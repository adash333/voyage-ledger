# SPEC-018 かいけいの きほん（小学生向け会計入門ページ）

更新日: 2026-10-20
状態: Approved for implementation
対象: `/learn/`（日本語）。英語版 `/learn/en/` は将来拡張。

## 1. 目的と位置づけ
- 小学3年生以上が、親の助けなしに約5分で「お金の動きを2つの面から見る」複式簿記の考え方をつかむ入口ページ。
- 既存の「帳簿の世界史」（歴史の読み物）、「こしょうやさん」（低学年向けゲーム）とは役割を分け、ゲームで遊ぶ前の説明と、遊びながら戻って確認する辞書を兼ねる。
- トップページでは「こしょうやさん」の直後に置く。
- 既存教材・ゲーム・セーブデータは変更しない。外部API・保存データなし（ふりがな設定だけ localStorage）。

## 2. 対象と表現
- 対象学年の下限は小学3年生。本文中のすべての漢字にふりがな（`<ruby>`）を付け、「ふりがな あり／なし」で切り替えられる（設定は `voyage-learn-ruby-v1` に保存）。
- 1ステップはスマホ1画面程度。文は短く、数字は金貨の枚数で統一。点数・順位・罰点なし。
- 用語はゲームと同じ言葉（金貨、コショウ、船、仕訳、売上、もうけ）を使い、正式名称を併記する（例: もうけ（利益））。

## 3. 構成
1. **お金は「どこから来て、どこへ行った」の2つで書く**（仕訳）。金貨60枚でコショウを買う→左「商品60」右「現金60」。90枚で売る→左「現金90」右「売上90」。左右の合計が常に等しいことを数字で示す。
2. **持ち物と、お金の出どころ**（貸借対照表）。宝箱（現金・商品・船）と出どころ（借りたお金・自分のお金）を天秤で見せる。「銀行から100借りる」「船を100で買う」「はじめにもどす」で、常につり合うことを体験。
3. **もうけは「売ったお金 − かかったお金」**（損益計算書）。10ふくろ（1ふくろ6枚）仕入れ、9枚で売る。売れた数を0〜10で動かすと、売上・原価・もうけ・残りのコショウ・金貨が変わる。「金貨が減っても、コショウが残っていれば財産は減っていない」を示す。
4. **金貨が減っても、ソンじゃない**（減価償却）。船500枚を買っても財産は同じ。「1回航海する」ごとに25枚が費用になり、20回で0になる。
5. **借りたお金と、預かったお金**（借入と株式）。銀行から借りる→返す＋利息（レンタル料）。仲間に出してもらう（株）→返さないかわりに、もうけを分ける（配当）。
- **用語カード**10枚（現金、商品、売上、費用、もうけ（利益）、財産（資産）、借金（負債）、自分のお金（資本）、仕訳、減価償却）。タップで裏返り、子ども向けの言い換えを表示。
- **どっちが正しい？**3問。選ぶとすぐに理由を表示。間違えても責めない。
- **つぎは ゲームで**: こしょうやさん → 自由経営モード（中級編）→ 株式会社版（上級編）、読み物「帳簿の世界史」へのリンク。

## 4. 実装
- `learn/index.html`（本文。漢字は `漢字{よみ}` の記法で書き、読み込み時に `<ruby>` に変換）、`learn/app.js`（変換・ふりがな切替・体験の描画）、`learn/content.mjs`（計算の純粋関数、用語カード、クイズのデータ）、`learn/style.css`。
- 純粋関数: `rubyHTML(text)`、`purchaseEntries()`、`balanceAfter(actions)`、`profitFor(sold)`、`shipWear(voyages)`、`financingCompare()`。
- トップページ `index.html` の「こしょうやさん」の直後に「📘 かいけいの きほん（入門）」を追加。README に一文追加。`package.json` の `check` に新規ファイルを追加。

## 5. 受入基準
1. `learn/index.html` の本文と `content.mjs` の文字列に、読みのない漢字がない（単体テストで検査）。
2. 各体験の計算: 仕訳の左右一致、天秤の左右一致、売れた数ごとの売上・原価・もうけ・残り、減価償却の帳簿価額（500→0、25枚×20回、マイナスなし）。
3. クイズの正解番号と理由が揃っている。用語カードが10枚。
4. ふりがな切替で `rt` が非表示になり、設定が再読み込み後も保たれる。
5. 360px幅で横はみ出しなし。体験の操作で数字が変わる。トップページからのリンク。
6. 既存テストの回帰なし。`npm run check` と E2E が成功してから公開。
