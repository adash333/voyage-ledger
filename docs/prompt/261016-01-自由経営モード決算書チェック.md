- その他の確認: 会計ロジック（FIFO 原価、航海費、特別決算、改ざん検出付き復元）に問題なし。favicon が無いためコンソールに 404 が 1 件出るが動作には影響しない。

## 追加依頼 3：favicon の追加

### ユーザーのプロンプト原文
```text
favicon を追加して 404 をなくして
```

### 結果
- 404 の原因は、`<link rel="icon">` が無いためブラウザがドメイン直下の `/favicon.ico`（GitHub Pages では `adash333.github.io/favicon.ico`）を自動で探しに行くこと。リポジトリ外のパスなので、各ページにアイコンのリンクを明示して解決した。
- `favicon.svg`（トップページの帆船イラストを元にした 64×64 の SVG）を作成。そこから `favicon.ico`（16/32/48px）と `apple-touch-icon.png`（180px）を生成。
- 全 12 ページの `index.html` の `</title>` 直後に、階層に応じた相対パスで `rel="icon"`（SVG と ICO）と `rel="apple-touch-icon"` のリンクを追加。
- `tests/e2e/favicon.spec.mjs` を追加。12 ページそれぞれでアイコンリンクが 3 つあり、すべて 200 で取得でき、ページ読み込み中に 4xx/5xx の応答が無いことを検証。

### 検証
- `npm run check`: 構文検査と単体テスト 25 件成功。
- Playwright E2E（mobile-chromium）: 48 件すべて成功（既存 36 件 + favicon 12 件）。
