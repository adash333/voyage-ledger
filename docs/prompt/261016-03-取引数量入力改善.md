# 取引数量の入力改善

## ユーザーのプロンプト原文
```text
20で　取引内容を確認する　を押すと、うまくいきません　修正してください

あと、数値を増減できる、小さいボタンも設置してください
```

添付：19314.jpg。アレクサンドリアでコショウ20を買おうとして、画面下に「確認できません：Ship full」と表示されたスマートフォン画面。

## 結果
- origin/mainをfetchし、着手時のmainが最新であることを確認。
- 原因は既存の仕様で船の積載が全商品合計10個までである一方、数量欄に上限の説明がなく、20を入力すると確認時に画面下の英語エラーだけが表示されることだった。
- 積載上限を維持するか20へ増やすかを任意質問した。回答がないため既存仕様の10個を維持し、会計エンジン・保存形式は変更していない。
- `trade/app.js` で、積載の空き・所持金・選択商品の在庫に応じた取引可能数を計算し、数量欄の近くに表示。20などの上限超過、現金・在庫不足、空欄・0・負数・小数は日本語で理由を表示し、不正な取引や保存データの変更を防ぐ。入力した数量は勝手に別の数量へ変更しない。
- `trade/index.html`・`trade/style.css` に「−」「＋」の小さなボタンを追加。1個ずつ増減でき、1未満への減少や取引上限を超える増加を防ぐ。44px以上の操作領域、読み上げ用ラベル、説明との関連づけを追加。
- 数量・売買区分・商品を変更した時点で古い確認画面を閉じ、変更前の内容を確定できないようにした。取引後・出航後・再読み込みでも上限表示を更新。
- CSSとJSの読み込みURLを更新し、既存ブラウザのキャッシュ対策を実施。地図・船の移動、ブラウザ自動保存、やり直しの動作は維持。
