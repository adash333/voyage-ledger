# 独自ドメイン移行の相談

## 日付
2026-11-08（Asia/Tokyo）

## ユーザーのプロンプト原文
```text
今　https://adash333.github.io/voyage-ledger/　にサイトがありますが、将来、Googleアドセンスやアマゾンアフィリエイトをしたいので、サイトを 5micro.net のサブドメインに公開したいです。どうしたらよいですか？
```

## 結果
- 調査でわかったこと
  - 公開は GitHub Actions（`.github/workflows/deploy.yml`）→ GitHub Pages。Actions 方式なので `CNAME` ファイルは不要で、独自ドメインは Settings → Pages で設定する。
  - HTML/JS のリンクはすべて相対パスなので、サブドメインのルートに移ってもコードの修正なしで動く。
  - 独自ドメイン設定後、旧 URL（github.io）は新ドメインへ自動で 301 リダイレクトされる。
  - localStorage はドメインごとに別なので、旧 URL のセーブデータは引き継がれない。
- 追加したファイル: `docs/custom-domain.md`（移行手順書）
  - GitHub でのドメイン確認（TXT）→ DNS の CNAME（`<サブドメイン>` → `adash333.github.io`）→ Settings → Pages の Custom domain → Enforce HTTPS の順に説明。
  - AdSense（ルートドメインで登録、`ads.txt` はルートドメインに置く）、Amazon アソシエイト（表記が必要）、プライバシーポリシー・運営者情報などの準備事項、GitHub Pages の利用規約上の注意を記載。
- `CNAME` はまだ追加していない（DNS を設定する前に追加すると、github.io の URL がまだ存在しないドメインへリダイレクトされて見られなくなるため）。

## 検証
- `npm run check` → 成功（fail 0）
- ドキュメント追加のみで画面の変更はないため、E2E は実行していない。

## 追加依頼 2：さくらインターネットで TXT レコードを追加する方法

### ユーザーのプロンプト原文
```text
表示された TXT レコードを 5micro.net の DNS に追加し、Verify を押します。　のやり方を教えてください　さくらインターネットです
```

### 結果
- さくらインターネットでの手順を回答した（コードの変更はなし）。
  - GitHub: Settings → Pages → Add a domain → `5micro.net` → 表示された TXT の名前と値を控える。
  - さくら: 契約サービスによって入口が違う。レンタルサーバ契約中ならサーバコントロールパネル →「ドメイン/SSL」→ 対象ドメインの「DNS設定」、ドメインのみ契約ならドメインコントロールパネル → 対象ドメインの「ゾーン」→ 編集。
  - エントリ名は `_github-pages-challenge-adash333` だけを入れる（`.5micro.net` は自動で付く）。種別は「テキスト(TXT)」、値は引用符なしで貼り付ける（引用符はさくらが自動で付ける）。
  - 保存後、数分〜数時間待ってから GitHub の Verify を押す。失敗しても時間をおいて再試行すればよい。
  - 確認コマンド: `dig +short TXT _github-pages-challenge-adash333.5micro.net`
- `docs/custom-domain.md` の手順 1 に、さくらでの入力例を追記した。

### 検証
- ドキュメントのみの変更。`npm run check` → 成功。

## 追加依頼 4：サブドメイン名の決定

### ユーザーのプロンプト原文
```text
v.5miro.net にしたいです
```

### 結果
- `v.5micro.net` として案内した（原文の「5miro」は「5micro」の打ち間違いと判断）。
- DNS の現状を DNS-over-HTTPS（dns.google）で確認した。
  - 5micro.net のネームサーバは `ns1.dns.ne.jp` / `ns2.dns.ne.jp`（さくら）。
  - `_github-pages-challenge-adash333.5micro.net` の TXT は反映済み。
  - `v.5micro.net` はまだ存在しない（NXDOMAIN）。CNAME の追加はこれから。
- 案内した手順: さくらで CNAME（エントリ名 `v`、値 `adash333.github.io.`）を追加 → リポジトリの Settings → Pages → Custom domain に `v.5micro.net` を入れて Save → Enforce HTTPS。
- README・ブログの URL 書き換えは、`https://v.5micro.net/` が開くようになってから行う（先に書き換えるとリンク切れになるため）。

### 検証
- 記録のみの変更（コードの変更なし）。

### 結果

- 旧 URL `https://adash333.github.io/voyage-ledger/learn/` → 301 で `http://v.5micro.net/learn/` に転送されている。
- 残り: GitHub の DNS チェック完了と証明書発行を待ち（通常数分〜1時間、長いと 24 時間）、Enforce HTTPS を有効にする。その後 README・ブログの URL を書き換える。
