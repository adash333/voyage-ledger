# 自由経営モードのセーブデータ JSON 保存・読み込み

## 日付
2026-10-18（Asia/Tokyo）

## ユーザーのプロンプト原文
```text
データをJSON形式で保存　のボタン
また、途中から始めるためにデータをアップロードするためのボタン
をつけてください。そのための実装もお願いします
```

## 結果
- `trade/save.mjs` を追加。`exportSave(state)` は `restore` で検証した状態を `{app:"voyage-ledger-trade", format:1, exportedAt, state}` の JSON と `voyage-trade-YYYYMMDD-HHMM.json` のファイル名にまとめる。`parseSave(text)` はラッパー形式と状態単体の両方を受け付け、`restore` で取引履歴を再計算して検証し、JSON でない・このゲームのファイルでない・改ざんされた取引を拒否する。
- `trade/index.html`・`trade/en/index.html`: 航海結果の下に「💾 セーブデータ」欄を追加。「データをJSON形式で保存」ボタン（Blob をダウンロード）と「JSONファイルから続きを始める」（ファイル選択）を配置。英語版は「Save data as JSON」「Continue from a JSON file」。
- `trade/app.js`・`trade/en/app.js`: 保存・読み込みの処理を追加。読み込み時は「いまの進行状況を、ファイルの内容（第N航海）に置き換えますか？」と確認し、キャンセルや不正なファイルでは既存データを変更しない。成功すると自動保存を上書きして再描画し、売買タブに戻る。結果は `#saveMessage` に表示。
- `trade/style.css`: ファイル選択ラベルをボタン風に表示。キャッシュ対策として読み込み URL を更新。`package.json` の構文検査に `trade/save.mjs` を追加。
- `specs/016-trade-save-file.md` を追加、README に一文追記。
- `tests/trade.test.mjs` に書き出し形式・読み込み・不正ファイル拒否の単体テスト 2 件、`tests/e2e/trade-save.spec.mjs` に E2E 3 件（保存 → やり直し → 読み込みで途中再開と再読み込み後の維持、キャンセル・不正 JSON・別アプリ・改ざんファイルで状態不変、英語版の往復）を追加。
