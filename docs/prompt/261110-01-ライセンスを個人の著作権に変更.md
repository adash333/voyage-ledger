# ライセンスを個人の著作権に変更

## 日付
2026-11-10（Asia/Tokyo）

## ユーザーのプロンプト原文
```text
https://github.com/adash333/voyage-ledger　ですが、MITになっていますが、自分個人にしたいです。どうしたらよいですか？
```

## 結果
- `LICENSE`: MIT（著作権者「Voyage Ledger contributors」）をやめ、「Copyright (c) 2026 adash333. All rights reserved.」の全著作権保持の表記（日本語＋英語）に変更。複製・改変・再配布・商用利用は許可制、公開サイトで遊ぶ・読むのは自由、GitHub で閲覧できるのは GitHub 規約によるもので利用許諾ではないこと、2026-11-10 より前に配布した版は MIT のまま、を明記。
- `package.json`: `"license": "UNLICENSED"`（npm での「非公開ライセンス」の書き方）を追加。
- `README.md` のライセンス欄、`about/index.html`（ソースコード欄と「ご利用にあたって」に著作権の一文）、`docs/blog/261020-大航海商人アカデミー紹介記事.md` / `.html` の「MIT ライセンス」表記を更新。
- ユーザーに伝えた注意:
  - すでに MIT で公開していた版は取り消せない（その時点で取得・フォークした人は MIT の条件で使える）。今後の版から適用される。
  - コミットの作者は adash333（2つのメールアドレス）と Claude のみで、他人の貢献はないため、本人だけの判断で変更してよい。
  - リポジトリを非公開（Private）にする方法もあるが、GitHub Free では Private リポジトリの GitHub Pages は使えず、サイトが止まる。Private にするなら GitHub Pro（有料）にするか、Cloudflare Pages などへ移す必要がある。
  - GitHub のリポジトリ画面右側の「MIT license」表示は、LICENSE の push 後に自動で消える。
