# Voyage Ledger MVP 仕様書

## 対象と目的
小学4〜6年生を中心に、現金と利益の違い、資産・資本金、借方・貸方、損益計算書と貸借対照表を体験的に学ぶ。

## 取引
1. 元手100金貨：借方 現金100 / 貸方 資本金100
2. 商品60金貨を現金仕入れ：借方 商品60 / 貸方 現金60
3. 商品を90金貨で売る：借方 現金90 / 貸方 売上90、および借方 売上原価60 / 貸方 商品60
4. 結果：現金130、商品0、資本金100、利益30

## 不変条件
- 各仕訳の借方と貸方の金額が一致する
- 資産＝負債＋純資産（初期版では負債なし）
- 売上−売上原価＝利益
- 現金と利益は別の概念

## 実装
HTML/CSS/JavaScript、依存ライブラリなし。進捗はlocalStorageに自動保存し、再読み込み時に既知の取引列との一致を検証して復元する。日本語版・英語版ともにJSONファイルの入出力UIは設けない。「最初から遊ぶ」または「Start over」で確認後に進捗を初期化し、その状態を自動保存する。

## 将来の拡張
仕訳選択クイズ、港・船・航海イベント、借入と返済、難易度別モード、テストとアクセシビリティ改善。

## 歴史
1500年のヴェネツィアは教材の舞台設定。複式簿記は大航海時代以前のイタリア商人の間で発達し、1494年にルカ・パチョーリが体系的に紹介した。

## v0.2 表示改善
商品はコショウ10袋（仕入れ総額60金貨）と明示する。決算書は損益計算書と貸借対照表を図解で分離。売上と仕入れ原価を棒グラフで表示し、財産と出どころを左右比較する。仕訳行のタップで説明を表示。販売単価3〜12金貨のシミュレーターを追加（帳簿を変更しない練習モード）。
